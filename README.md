# React Practice Projects

This repository is a collection of small React projects created to practice core concepts step by step. Each folder is a mini app focused on a specific topic such as JSX, props, state, hooks, forms, UI layout, and Tailwind CSS.

The goal is to build strong fundamentals before moving to larger real-world applications.

---

## Learning Journey

The projects are arranged in a simple learning order:

1. Basic React setup and component structure
2. Props and component communication
3. useState and state updates
4. Event handling and forms
5. UI design and layout
6. Styling with Tailwind CSS
7. Reusable component design

## Folder-wise Summary

### 1. card-Task
This project is a card-based UI that displays job openings or company postings. It helps understand:

- array mapping
- reusable Card component
- passing props into child components
- rendering list items dynamically

### 2. Card-task2
This project focuses on profile cards. It demonstrates:

- data-driven UI
- multiple card rendering
- object-based data structures
- props usage for repeated components

### 3. form-handling
This is a beginner form project. It shows:

- form submit events
- `preventDefault()`
- input fields
- basic event handling in React

### 4. intro-functions
This project introduces function-based interaction. It covers:

- event handler functions
- function calls from button clicks
- JavaScript inside React components

### 5. Intro-tailwindCss
This project helps start with Tailwind CSS in React. It teaches:

- Tailwind setup in Vite
- utility-first styling
- fast UI creation using classes

### 6. React-intro
This is the first real React learning folder. It contains core React basics such as:

- component creation
- JSX syntax
- dynamic rendering
- clean React project structure

### 7. Ui-Design-Project
This is a design-oriented mini project. It includes section-based UI structure and reusable components like cards, headers, and content blocks. It helps improve:

- page layout design
- segmentation of UI into components
- reusable section architecture
- responsive styling concepts

### 8. Understanding Hooks - useState
This is the simplest state-management practice project. It demonstrates:

- `useState()`
- increment/decrement buttons
- state changes on click
- value rendering in UI

### 9. Understanding_Props
This folder is dedicated to props. It shows how data flows from parent to child and how one UI component can be reused for different data. Topics include:

- component props
- child component reusability
- list rendering with props

### 10. useState -- Advance
This project goes a little beyond the basics and expands state practice. It helps with:

- repeated state updates
- interaction logic
- improving React thinking for event-driven apps

## How to Run Any Project

Go into any folder and run:

```bash
npm install
npm run dev
```

Example:

```bash
cd React-intro
npm install
npm run dev
```

## What You Should Learn From This Repository

By the end of these projects, a learner should be able to understand:

- how React components work
- how props pass data between components
- how state updates the UI
- how forms and buttons trigger events
- how to structure reusable UI
- how to style React apps with CSS and Tailwind
